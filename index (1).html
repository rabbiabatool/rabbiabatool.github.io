Projects

Marginalia: chat with your PDFs

A full-stack chat app where you upload a PDF and ask questions about it. Answers are generated by the Claude API and grounded in the document using retrieval-augmented generation (RAG) with MySQL full-text search.

Users sign in with JWT authentication, manage conversations (create, rename, delete, search), and can listen to answers through the Web Speech API.
